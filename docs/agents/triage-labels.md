# Triage labels

| Role            | Label             | Meaning                                         |
| --------------- | ----------------- | ----------------------------------------------- |
| needs-triage    | `needs-triage`    | New, not yet assessed                           |
| needs-info      | `needs-info`      | Blocked on an answer from the reporter          |
| ready-for-agent | `ready-for-agent` | Specified well enough for an agent to implement |
| ready-for-human | `ready-for-human` | Needs a human decision or hands-on work         |
| wontfix         | `wontfix`         | Declined, with the reason in a comment          |

Apply these exact strings. Create a label with `gh label create` only if it does not exist yet.
