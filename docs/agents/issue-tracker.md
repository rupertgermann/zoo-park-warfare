# Issue tracker

Issues for this repo live in GitHub Issues: https://github.com/rupertgermann/zoo-park-warfare/issues.
Use the `gh` CLI from the repo root.

- Create: `gh issue create --title "<title>" --body-file <file> --label <label>`
- Read: `gh issue view <number> --comments`
- List: `gh issue list --state open --label <label>`
- Comment: `gh issue comment <number> --body-file <file>`
- Relabel: `gh issue edit <number> --add-label <label> --remove-label <label>`
- Close: `gh issue close <number> --comment "<reason>"`

## PRs as a request surface

Off. Only issues count as requests. Pull requests are not triaged.
